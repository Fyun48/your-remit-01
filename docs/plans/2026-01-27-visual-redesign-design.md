## 1. 整體視覺系統

### 色彩系統

| 用途 | 色碼 | 說明 |
|------|------|------|
| 主色 | `#1B3A57` | 深藍，用於標題、背景 |
| 主色深 | `#0D1E2D` | 更深藍，用於 Hero 背景 |
| 強調色 | `#2DBDB6` | 青綠，用於 CTA、hover、裝飾 |
| 漸層 | `linear-gradient(135deg, #1B3A57 0%, #2DBDB6 100%)` | 按鈕、裝飾 |
| 文字深 | `#0D1E2D` | 淺色背景上的文字 |
| 文字淺 | `#FFFFFF` | 深色背景上的文字 |

### 字體排版

- **標題字體**：Poppins（英文）+ Noto Sans TC（中文）
- **內文字體**：Noto Sans TC
- **Hero 標題字級**：`clamp(3rem, 8vw, 7rem)`
- **字重對比**：標題 900、內文 400

### 設計語言

- **圓角**：卡片 `16px`、大區塊 `24px`
- **陰影**：`0 20px 60px rgba(27, 58, 87, 0.3)`（帶品牌色）
- **所有互動元素都有 hover 動畫**

## 6. 動態效果與技術實現

### 滾動動畫

- Intersection Observer API 偵測
- 進場效果：fade-in-up
- 數字計數器進入視窗時啟動
- 視差使用 CSS transform

### 滑鼠互動

- Hero 幾何裝飾跟隨滑鼠
- 按鈕 hover：`scale(1.05)` + 陰影擴散
- 卡片 hover：`translateY(-8px)` + 陰影加深

### 技術選擇

- **純 CSS + Vanilla JavaScript**（不引入框架）
- CSS 變數管理主題色彩
- 動畫使用 `@keyframes` + `animation`
- 響應式使用 `clamp()` 和 `min/max`

### 效能考量

- 動畫只用 `transform` 和 `opacity`（GPU 加速）
- 圖片 lazy loading
- 避免 layout thrashing
