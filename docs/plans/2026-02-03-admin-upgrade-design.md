## 一、影音管理改進

### 1.1 名稱與介面變更

| 項目 | 變更內容 |
|------|----------|
| 選單名稱 | 「圖片管理」→「影音管理」 |
| 分組預設值 | `default` → `預設` |
| 預設顯示模式 | 改為列表模式（非網格） |
| 雙擊操作 | 雙擊任一項目 = 開啟編輯視窗 |
| 移除功能 | 刪除「顯示在輪播圖選擇中」勾選框 |

### 1.2 檔案類型與列表顯示

列表欄位：
- 縮圖（影片顯示第一幀或預設影片圖示）
- 檔案名稱
- 類型（圖片 / 影片）
- 分組
- 檔案大小
- 上傳時間
- 操作按鈕

支援格式：
- 圖片：JPG、PNG、GIF、WebP
- 影片：MP4、WebM

### 1.3 上傳時自動分組

- 上傳檔案時，自動歸入當前下拉選單選擇的分組
- 若選擇「全部」或「預設」，則歸入「預設」分組

### 1.4 檔案大小檢查與壓縮

上傳流程：
1. 使用者選擇檔案
2. 檢查檔案大小是否超過上限（從系統設定讀取）
3. 超過 → 彈出確認視窗詢問是否壓縮
4. 確定 → 前端壓縮後上傳
5. 取消 → 取消上傳
6. 未超過 → 直接上傳

### 1.5 圖片/影片自動縮放

當圖片或影片被使用於輪播圖或內容區塊時：
- 小於版區尺寸 → 等比例放大填滿（object-fit: cover）
- 大於版區尺寸 → 等比例縮小填滿（object-fit: cover）
- 不改變原始檔案，僅在顯示時 CSS 自動調整

### 1.6 輪播圖影片支援

影片用於輪播圖時的行為：
- 自動播放（autoplay）
- 靜音（muted）
- 循環播放（loop）
- 不顯示控制列

## 四、登入安全機制

### 4.1 登入失敗處理

- 第 1-2 次失敗：顯示「帳號或密碼錯誤」
- 第 3 次起：顯示 8 位圖形驗證碼
- 驗證碼帶干擾線條
- 點擊可重新產生
- 關閉瀏覽器後重置失敗次數

### 4.2 忘記密碼流程

1. 使用者輸入 Email
2. 系統檢查是否存在
3. 存在 → 產生隨機密碼，透過 SendGrid 寄送
4. 不存在 → 顯示「查無此 Email」

### 4.3 資料庫結構

`admin_users` 資料表：
| 欄位 | 類型 | 說明 |
|------|------|------|
| id | UUID | 主鍵 |
| email | TEXT | 登入帳號 |
| password_hash | TEXT | 密碼雜湊 |
| name | TEXT | 顯示名稱 |
| role | TEXT | admin/editor/viewer |
| status | TEXT | active/disabled |
| created_at | TIMESTAMP | 建立時間 |
| last_login | TIMESTAMP | 最後登入時間 |

`audit_logs` 資料表：
| 欄位 | 類型 | 說明 |
|------|------|------|
| id | UUID | 主鍵 |
| user_id | UUID | 操作者 ID |
| user_email | TEXT | 操作者 Email |
| action | TEXT | create/update/delete |
| module | TEXT | 模組名稱 |
| item_id | TEXT | 項目 ID |
| item_name | TEXT | 項目名稱 |
| details | JSONB | 變更詳情 |
| created_at | TIMESTAMP | 操作時間 |

## 五、技術實作重點

1. **前端圖片壓縮**：使用 Canvas API 壓縮圖片
2. **前端影片處理**：影片不壓縮，僅檢查大小
3. **圖形驗證碼**：前端 Canvas 產生，含干擾線
4. **密碼雜湊**：使用 bcrypt 或 Web Crypto API
5. **SendGrid 整合**：透過 Supabase Edge Function 發送郵件
